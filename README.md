# 國中國文 1 上　互動學習單（康軒版）

單一 HTML 檔案的互動學習單，開啟即用，不需安裝、不需連線、不需帳號。
作答與學習紀錄存在使用者自己的瀏覽器裡（localStorage），不會上傳到任何地方。

由王麗玲老師編寫，搭配「小夫子」國文小幫手：進站自我介紹（含語音）、
每一關一句提示、對完答案送一張鼓勵小卡。

## 怎麼用

開 `index.html` 就是總覽頁，從那裡點進各課。
若要放到網路上，在 GitHub 開一個 repository，把這個資料夾裡的檔案全部上傳，
再到 Settings → Pages 把來源設成 main 分支的根目錄，等一兩分鐘就會有網址，
形式是 `https://<你的帳號>.github.io/<repository 名稱>/`。

## 每一份的結構

課內十四份都是課本導覽加七個練習關卡，作答後立刻對答案看解析，
寫作關卡的文字會留在瀏覽器裡。成語典故那一份是目次、篇、單元、測驗四層，
單元頁可以逐條或整單元連續朗讀。

## 需要注意的

- 語音朗讀用瀏覽器內建的語音合成，需要系統裝有中文（臺灣）語音。
  手機第一次要由使用者按一下播放鈕，瀏覽器才允許發聲。
- 紀錄存在瀏覽器裡，換一台裝置或清除瀏覽資料就會歸零，不會跨裝置同步。
- 檔案較大（每份約 450 KB，整冊 620 KB），因為角色圖是內嵌的，
  好處是單一檔案就能用，複製給學生不會缺圖。
- 建議用 Chrome、Edge 或 Safari 的較新版本。
